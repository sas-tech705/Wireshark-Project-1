# 🦈 Wireshark Project 1: Network Traffic Analysis

## 📌 Project Overview

This project focuses on using **Wireshark**, a network protocol analyzer, to capture, monitor, and analyze network traffic generated by my laptop while accessing a website.

The practical exercise involved capturing network packets during a connection to **networkwalks.com** and examining the captured traffic to understand how devices communicate over a network.

Through packet analysis, I was able to identify my laptop's IP address, DNS server address, the website's IP address, and examine the TLS handshake to understand how secure connections are established.

This project provided hands-on experience in network monitoring, packet inspection, DNS resolution, and encrypted web communication.

## 🎯 Project Objectives

The main objectives were to:

* Understand how Wireshark captures network traffic.
* Identify the IP address assigned to my laptop.
* Identify the DNS server responsible for resolving domain names.
* Determine the IP address associated with a website.
* Examine the TLS Client Hello packet.
* Identify the server name (SNI) transmitted during the TLS handshake.
* Identify the port used for secure communication.
* Determine the TLS version used by the website.

## 🔬 Practical Implementation

### Step 1: Installing Wireshark

I installed Wireshark on my Windows PC to monitor and capture network traffic.

After installation, I selected the active network interface connected to the internet and started capturing packets.

### Step 2: Generating Network Traffic

With packet capture running, I opened a web browser and accessed:

**Website:** https://networkwalks.com

Wireshark captured the network traffic generated during the connection, including DNS queries, DNS responses, TCP communication, and TLS handshake packets.

### Step 3: Analyzing the Captured Packets

I used Wireshark display filters to isolate relevant packets and examine the information required to answer the project questions.

Some useful filters include:

* `dns` – Displays DNS queries and responses.
* `ip.addr == <IP_ADDRESS>` – Filters traffic involving a particular IP address.
* `tls` – Displays TLS packets.
* `tcp.port == 443` – Displays TCP traffic using port 443.
* `tls.handshake.type == 1` – Displays TLS Client Hello packets.

## ❓ Project Questions and Answers

The following questions were investigated during the practical exercise.

### 1. What is the IP address of your own laptop?

**Answer:** 10.46.23.63

**Explanation:**

The laptop's IP address identifies it on the local network. It allows other devices on the network to communicate with it.

I identified this address by examining the source IP address of packets generated by my laptop during the capture.

**Screenshot:** `screenshots/question-1.png`

### 2. What is the IP address of your DNS server?

**Answer:** 10.46.23.68

**Explanation:**

A DNS (Domain Name System) server translates human-readable domain names into IP addresses.

When I accessed networkwalks.com, my laptop sent a DNS query to a DNS server to resolve the domain name into its corresponding IP address.

I identified the DNS server by examining the destination IP address of the DNS query packet.

**Screenshot:** `screenshots/question-2.png`

### 3. What is the IP address of the website networkwalks.com?

**Answer:** 192.232.216.135

**Explanation:**

Websites are hosted on servers that have IP addresses. When a user enters a domain name into a browser, DNS resolution is performed to determine the IP address associated with that domain.

I identified the website's IP address by examining the DNS response packet captured in Wireshark.

**Screenshot:** `screenshots/question-3.png`

### 4. Which website name (Server Name) is sent in the TLS Client Hello?

**Answer:** networkwalks.com

**Explanation:**

During the TLS handshake, the client sends a Client Hello message to initiate a secure connection with the server.

The Server Name Indication (SNI) extension allows the client to indicate the hostname it wants to connect to.

In this practical exercise, I examined the TLS Client Hello packet and identified the server name as networkwalks.com.

**Screenshot:** `screenshots/question-4.png`

### 5. Which server port is used for the secure connection?

**Answer:** 443
**Explanation:**

A port number identifies a particular service or application running on a server.

HTTPS commonly uses TCP port **443** to provide secure communication between web browsers and web servers.

I identified the server port by examining the destination port in the TCP communication associated with the website connection.

**Screenshot:** `screenshots/question-5.png`

### 6. Which TLS version does the website use?

**Answer:** TLSv1.3

**Explanation:**

Transport Layer Security (TLS) is a cryptographic protocol designed to provide secure communication over a network.

It helps protect data exchanged between a client and a server through encryption and authentication.

I identified the TLS version by examining the version information in the TLS handshake packets captured by Wireshark.

**Screenshot:** `screenshots/question-6.png`
